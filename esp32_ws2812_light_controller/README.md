# ESP32-S3 WS2812 路灯灯带控制程序

这是一个**独立灯带控制程序**，用于后续快速调整 WS2812 灯带的灯珠数量和亮度，或进行灯带接线测试。

> 注意：它只控制灯带，不包含项目原 ESP32 程序中的 LD06、水位、气象站和 MQTT 功能。正式设备在找回或完成兼容的原 ESP32 综合程序前，不要直接用此程序覆盖。

## 接线

| 灯带端 | 连接位置 |
| --- | --- |
| `DIN` | ESP32-S3 `GPIO48` |
| `5V` | 外接稳定 5V 电源 |
| `GND` | 外接 5V 负极，并与 ESP32 `GND` 共地 |

不要用 ESP32 的板载 5V 给多颗 WS2812 灯珠供电；不要把 12V 接入灯带或 ESP32。

## 修改灯珠数量和亮度

打开 [config.h](config.h)，只修改这两行：

```cpp
#define LED_COUNT 30
#define LED_BRIGHTNESS 80
```

- `LED_COUNT`：灯带的实际灯珠总数。例如灯带有 60 颗，改成 `60`。
- `LED_BRIGHTNESS`：亮度范围 `0 ~ 255`。推荐先使用 `80 ~ 120`；灯珠越多，亮度越高，对 5V 电源电流要求越高。

修改后必须重新上传到 ESP32 才会生效。

## Arduino IDE 烧录步骤

1. 安装 Arduino IDE，并在开发板管理器安装 **esp32 by Espressif Systems**。
2. 在库管理器安装 **Adafruit NeoPixel**。
3. 用能传输数据的 USB 线连接电脑和目标 ESP32-S3；灯带外接 5V 可先断开，防止测试时过流。
4. 用 Arduino IDE 打开 `esp32_ws2812_light_controller.ino`。
5. 在“工具”中选择实际的 ESP32-S3 开发板和对应 COM 口。
6. 点击“上传”。若上传无法连接，按住 ESP32 的 `BOOT` 键后再点击上传，出现写入后松开。
7. 上传成功后接好外部 5V，灯带会默认显示绿色；打开串口监视器（115200）可输入 `red`、`yellow`、`green`、`off` 测试。

## 供电估算

WS2812 每颗灯最大白光电流约 60mA。按最大白光粗略估算：

| 灯珠数 | 建议 5V 电源能力 |
| ---: | --- |
| 30 | 至少 2A |
| 60 | 至少 4A |
| 120 | 至少 8A |

实际使用绿色/黄色且限制亮度时电流通常更低，但电源仍应留余量。
