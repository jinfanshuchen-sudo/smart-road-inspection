甲方使用者操作教程

请按顺序操作。


一、第一次使用前准备

1. 将交付包 pyhulax-main 解压到电脑任意位置。

例如：

D:\pyhulax-main

或：

C:\Users\用户名\Desktop\pyhulax-main

2. 确认电脑已安装 Python 3.11。

如果未安装，请先安装 Python 3.11。

3. 打开 pyhulax-main 文件夹。

4. 双击：

setup_environment.bat

5. 等待窗口自动安装环境。

看到下面提示时，表示环境安装完成：

Environment setup finished.
You can now run start_dashboard.bat

6. 关闭这个窗口。

注意：
第一次运行 setup_environment.bat 需要电脑能联网。
以后正常使用一般不需要再运行 setup_environment.bat。


二、每天使用步骤

1. 打开无人机电源。

2. 电脑连接无人机 Wi-Fi。

3. 打开 pyhulax-main 文件夹。

4. 双击：

start_dashboard.bat

5. 等待窗口中出现：

Running on http://127.0.0.1:5055

6. 浏览器会打开控制面板。

如果浏览器没有自动打开，请手动打开：

http://127.0.0.1:5055/

7. 使用过程中不要关闭 start_dashboard.bat 打开的窗口。


三、飞行前摆放

1. 无人机放在起点位置。

2. 无人机机头朝向 D0 板。

3. 00 板放在起点附近，用作起点和方向参考。

4. D0 板放在无人机正前方路径上。

5. 场地保持空旷。

6. 确认无人机电量建议在 40% 以上。

7. 操作人员准备好网页上的“紧急降落”按钮。


四、开始任务

1. 在网页中找到“无人机任务”区域。

2. 点击：

刷新任务状态

3. 确认页面显示：

任务状态：idle
当前阶段：等待任务

4. 点击：

开始执行任务

5. 等待无人机自动执行任务。

正常过程：

起飞
向前搜索
识别 D0
自动降落


五、怎么看任务成功

任务成功时，网页“无人机任务”区域会显示：

任务状态：completed
D0 识别：成功

如果无人机已经安全降落，并且页面显示 D0 识别成功，就表示本次任务完成。


六、怎么看电量

在网页“无人机任务”区域查看：

电量

如果电量过低，请先更换电池后再执行任务。


七、紧急降落

如果飞行过程中出现异常，请立即点击网页中的：

紧急降落

如果网页无响应，请使用官方 App 或遥控器处理。


八、查看气象站、积水、LD06 数据

打开控制面板后，查看以下区域：

气象站
积水检查
人车接近
消息记录

如果设备已接入并正常上传，页面会显示对应数据。

如果没有数据，请检查：

1. 对应设备是否通电。
2. 网络是否正常。
3. 控制面板左上方连接状态是否正常。
4. 消息记录中是否有新消息。


九、常见问题处理

问题 1：网页打不开

处理：

1. 确认 start_dashboard.bat 窗口没有关闭。
2. 确认窗口中有：

Running on http://127.0.0.1:5055

3. 手动打开：

http://127.0.0.1:5055/

4. 浏览器按 Ctrl + F5 刷新。


问题 2：网页按钮没有反应

处理：

1. 检查 start_dashboard.bat 窗口是否还开着。
2. 检查电脑是否连接无人机 Wi-Fi。
3. 点击“刷新任务状态”。
4. 如果仍无反应，关闭窗口后重新双击 start_dashboard.bat。


问题 3：无人机连接失败

处理：

1. 检查无人机是否开机。
2. 检查电脑是否连接无人机 Wi-Fi。
3. 等待 10 秒后重试。
4. 重新点击“刷新任务状态”。
5. 必要时重启无人机。


问题 4：D0 没有识别成功

处理：

1. 调整 D0 板位置，使它在无人机正前方。
2. 保证 D0 板无遮挡。
3. 保证光线充足，避免强反光。
4. 将无人机重新放回起点后再次执行任务。


问题 5：气象站、积水、LD06 没有数据

处理：

1. 检查设备是否通电。
2. 检查网络是否正常。
3. 等待几秒钟观察“消息记录”是否更新。
4. 点击常用命令中的“刷新状态”。


十、关闭系统

1. 确认无人机已经降落。

2. 关闭无人机电源。

3. 关闭浏览器页面。

4. 关闭 start_dashboard.bat 打开的窗口。

如果窗口提示：

Press CTRL+C to quit

可以按 Ctrl + C 停止服务，然后关闭窗口。


十一、不要做的操作

1. 飞行过程中不要关闭后端窗口。

2. 飞行过程中不要随意断开无人机 Wi-Fi。

3. 无人机未降落前不要关闭无人机电源。

4. 不要在人多、空间狭窄或有障碍物的地方测试。

5. 电量过低时不要执行任务。
